Built-in Variables

MacroDescriptionExample Output

{email_user}Local part (before @)john.doe
{domain}Domain part (after @)example.com

Custom Macros — {macro_name}

Custom macros are defined on the Macros page. Each macro has a name and a list of values. Use {name} anywhere in subjects, from names, or HTML bodies.

FeatureSyntaxBehavior
Random pick {greeting} Randomly selects one value from the macro's value list for each send. Set Rotate Every = 0.
Rotation {greeting} Cycles through values in order. Set Rotate Every = N to use value #1 for N sends, then value #2 for N sends, etc.
Where usable Subject line, From Name, HTML body, sender rotation list, PDF macro fields

Random Strings — [RANDSTR:...]

Generate random strings inline. Useful for unique IDs, tracking tokens, or link parameters.

SyntaxDescriptionExample Output
[RANDSTR:8:a-z:lower]8 lowercase lettersjfkwmxpq
[RANDSTR:12:a-z0-9:lower]12 alphanumeric lowercasek3mf9x2wp4hn
[RANDSTR:6:A-Z0-9:upper]6 uppercase alphanumericX8K3MF
[RANDSTR:16:a-zA-Z0-9:lower]16 mixed-case alphanumerickF3mX9wP4hN2jR7q
[RANDSTR:10:0-9:lower]10 digits4829173650
Format: [RANDSTR:length:charset:case]
Charsets: a-z, A-Z, 0-9, a-z0-9, A-Z0-9, a-zA-Z, a-zA-Z0-9
Case: lower, upper

Sender / Subject Rotation

Configured per-template on the Composer page.

FeatureDescription
Subject Macro The subject field in a template supports all macros: {greeting} — News for {email_user}
HTML Rotation List multiple HTML file paths. Set Rotate Every to cycle between them every N sends.
Sender Rotation List multiple Name <email> entries. Rotates the From header every N sends to distribute across sender identities.

PDF Macros

When PDF Macro Enabled is turned on for a template, PDF form fields are filled dynamically per recipient.

FeatureDescription
Field matching PDF form field names are matched to macro names. A field named greeting is filled with the resolved {greeting} macro.
Built-in fields email, email_user, domain fields are filled with recipient data.
Unique per recipient Each recipient gets a unique PDF attachment with personalized field values.

Usage Examples
