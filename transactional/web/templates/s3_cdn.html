IAM-Policy JSON zeigen 
{
  "Version": "2012-10-17",
  "Statement": [{
    "Effect": "Allow",
    "Action": [
      "s3:CreateBucket",
      "s3:PutBucketPolicy",
      "s3:PutBucketPublicAccessBlock",
      "s3:PutObject",
      "s3:PutObjectAcl",
      "s3:GetObject",
      "s3:DeleteObject",
      "s3:ListBucket"
    ],
    "Resource": [
      "arn:aws:s3:::*",
      "arn:aws:s3:::*/*"
    ]
  }]
}

Bucket automatisch anlegen

Mailer erstellt Bucket, schaltet „Block Public Access" aus, hängt Public-Read-Policy an und trägt den Bucket in die Account-Liste ein. Idempotent — falls Bucket schon dir gehört, wird nur konfiguriert.

Base-Logo hochladen → Varianten generieren

Ein Base-Logo hochladen, N Varianten (Pixel-Nudge pro Datei für unique Bytes), die werden round-robin auf alle Buckets des Accounts verteilt. Beispiel: 30 Varianten × 3 Buckets = 10 pro Bucket, drei verschiedene Origin-Domains. Nutzt den Proxy des Accounts falls konfiguriert.
