Auto-Freshness Reset

During long campaigns, periodically pause sending and regenerate the HTML template pool and/or logo variants. Each reset takes 5-15 seconds. 0 = off.
Logo regen only fires for image modes cid and url. text mode never reads variants so the reset is skipped. cloudinary mode reads CDN URLs from the logo group and would require re-uploading to Cloudinary, which we don't do here — the reset is skipped too.

Gradual Send (Warm-up Ramp)

Instead of hitting full sending speed immediately, linearly ramp from a small starting fraction up to 100% over a configurable window. Helps with cold-IP warm-up and avoids tripping per-hour ESP rate limits when a fresh campaign starts. Only affects the per-mail sleep delay — thread count and SMTP-pool cooldowns are unchanged.
Default 180 = 3 hours. Effective range 5 min – 24 h.
Fraction of full speed at t=0. 0.05 = start at 5% of full throughput. Lower = slower start. At configured ramp time, speed reaches 100%.
