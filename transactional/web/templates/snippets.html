Snippet Assembly

Pro Slot ein Pool. Sobald eine Kampagne Assembly Mode aktiviert hat, würfelt der Sende-Loop pro Mail aus jedem Slot einen aktiven Snippet und setzt sie in der Reihenfolge header → intro → body → outro → footer zusammen. Kombiniert mit Macros + Spintax + Anti-FP-Transforms ergibt das praktisch unendlich viele Varianten. Deaktivierte Snippets werden ignoriert. Leere Slots werden übersprungen.
