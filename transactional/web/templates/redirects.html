Per-Recipient Ref Parameter

{% if cfg.redirect_append_ref %} ON — every redirect link will be rewritten at send time. {% else %} OFF — links go out unchanged. {% endif %}
Example: https://share.google/abc123 → https://share.google/abc123?ref=amFuZUBleGFtcGxlLmRl. The recipient email is base64url-encoded — never visible in cleartext in URLs, CDN logs, or browser history. Decode: echo amFuZUBleGFtcGxlLmRl | base64 -d → jane@example.de. Uses &ref= if the link already has a query string. Works with S3 + Google Share links.
